Los WDB contienen los datos temporales y los WCFG la selección de señales. Se verificó la apertura de las tres bases con Vivado 2025.1. Para reabrir, usar File > Simulation Waveform > Open Database y elegir el WDB; si la vista no aparece, abrir el WCFG correspondiente y pulsar Zoom Fit. Conservar juntos ambos archivos.
