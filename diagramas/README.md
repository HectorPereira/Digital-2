# Diagramas del laboratorio 3

Abrir Laboratorio_3_Arquitectura.drawio en draw.io/diagrams.net. Contiene dos hojas editables: integración de Parte B y de Parte A. Las cajas, etiquetas y líneas son objetos editables, no capturas pegadas.

Los SVG y los PNG en figuras/ son vistas del mismo contenido. El informe usa los PNG de alta resolución. Para regenerar los fuentes vectoriales, ejecutar diagramas/generar_diagramas.py desde la raíz del laboratorio; la exportación PNG requiere un renderizador SVG.

Se mantuvo el mapeo físico final confirmado: A0..A3 grande 5,6,7,8; B0..B3 grande 1,2,3,4; reset chico 4. El diagrama de estados continúa como figura separada en el informe.
